Làm theo bài **Webhook là gì**:

1. Tạo một server Discord của riêng bạn (tab **Cài đặt** của track, bước 1).
2. Tạo một webhook trỏ vào kênh `#general` của server đó.
3. Copy webhook URL và cất vào chỗ an toàn, ví dụ trình quản lý mật khẩu hoặc một file chỉ nằm trên máy bạn.

Tick từng mục khi đã làm xong. Bài này không cần nộp gì: **không gửi webhook URL cho ai**, kể cả mentor.
