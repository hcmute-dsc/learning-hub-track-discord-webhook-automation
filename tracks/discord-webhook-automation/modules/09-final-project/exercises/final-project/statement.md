Làm một **bot thông báo** chạy tự động trên GitHub Actions và gửi vào server Discord riêng của bạn. Ý tưởng, yêu cầu và cách làm từng bước nằm trong bài **Hướng dẫn dự án cuối**.

## Nộp bài

Link repo GitHub public. README phải có link tới một lần chạy thành công và ảnh chụp tin nhắn trong Discord.

Mentor chấm theo rubric 100 điểm. Đạt từ 70 điểm là hoàn thành track.

**Không** đưa webhook URL vào repo, README hay ảnh chụp. Lỡ lộ thì xóa webhook trong Discord trước, rồi mới sửa repo (chương 5).
